# Workflow example

`mountain-badge.svg` is the original authored CutCraft manual design, copied byte-for-byte from
1.0.5 (`39654a9465ecdef7478703ee586276304dbc29c6`), MIT OR Apache-2.0.

Use the same file for native/web Side by side, Overlay and Cut Preview comparisons, background
choice, colour inclusion, materials/mats/media/aids, save/reopen and simulated cut/test workflows.
The source artwork and cut lines must share a physical transform: the sun and mountain outlines
must align in Overlay. See [F22 and workflow acceptance](../../docs/design-audit/acceptance.md).
