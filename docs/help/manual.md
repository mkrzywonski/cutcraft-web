# CutCraft user manual

CutCraft prepares designs for cutting. Make artwork in an editor such as VectorCraft or Illustrator, then open it here to review the cut lines, choose material settings and place the design on a mat.

This manual is included with CutCraft and works without internet access. External links in other Help guides still need an internet connection.

## Open a design

Choose Open in the toolbar or File menu, or drop a file onto the window. Supported design formats are SVG, SVGZ, PDF, compatible Illustrator AI, ASCII DXF, PNG, JPEG, GIF and BMP. Open from library retrieves a saved project; Recent designs lists your uploaded designs. Opening a file uploads a private copy to your CutCraft server and does not change the original on your computer.

For text, save an outlined copy from your design editor. Keep the editable original separately. Photos and mockups usually need tracing or other preparation in an editor first. Help > How to save designs for cutting explains file formats and font questions.

Pictures use their recorded resolution, or 96 DPI when none is supplied. Very small pictures start at one inch on their longest edge; oversized pictures fit the mat. Change their size in Cut Preview.

## Review Issues and Info

Make cut-ready runs when a design opens. Issues describe decisions or problems that must be resolved before cutting. Read each card and choose the treatment you intend. Show me identifies the affected artwork. Info explains automatic preparation changes and offers alternatives where available.

Undo reverses a decision; Clear answers removes the preparation answers. Run again repeats preparation. Preparation does not edit the original file. For a design that needs drawing changes, return to your editor, save the changes and use File > Update from Design to upload the revised file.

## Compare artwork and cut lines

Side by side shows the source artwork and the cut lines together. Overlay draws cut lines over the source. These views share zoom and pan. Use the toolbar zoom controls or Fit in window to inspect the result.

Cut Preview shows the physical mat. Here the size controls change the design size rather than zooming the mat. The right panel is available in all three views.

What to cut groups shapes by colour or layer. Untick a row to leave it out of the cut. Included rows cut from the same piece of material. For different vinyl colours, cut the corresponding rows separately and use layering marks if needed.

## Choose a material and adjust settings

Selecting a material loads its saved blade depth, force, speed, passes, mirror and overcut settings. Adjust them in the right panel. Blade depth is a physical dial instruction on the original Cameo: change the actual blade dial to match.

Force presses the blade into the material. Speed controls movement. Passes repeats the cut. Mirrored flips the design for materials such as iron-on. Overcut extends closed contours slightly beyond their start to help them separate. Advanced contains blade-offset compensation.

Save updates the selected material preset. Save As creates a separately named preset. Unsaved adjustments remain with the design session across browser reloads and service restarts, until you select another preset or close the design session. Saving a project records its own sheet settings without overwriting the material preset.

Edit > Materials opens the preset library. Single-click selects an item so it can be duplicated or deleted; Edit opens its settings. Help > Troubleshooting explains which settings to try for shallow cuts, tearing, lifting material and other common problems.

## Choose a mat and place the design

Select your mat in the right panel. Edit > Mats manages mat profiles. Check the profile's outer size, sticky area, printed rulers and cutter start corner against your physical mat.

For an offcut, enable the piece-of-material option in Media, enter its dimensions and position, and place it on the mat accordingly. The yellow rectangle represents that piece. Drag it to move it; drag its corner or edge handles to resize it. Its opposite edges stay fixed.

Drag the design to position it. Drag any design corner to resize it with linked proportions; the opposite corner stays fixed. Double-click a displayed dimension to type a length. You can enter units explicitly, for example 1.5 in or 40 mm. Position, rotation and size also have controls in the right panel. Undo reverses a completed gesture in one step.

Snap to grid helps align positions and dimensions. Fit design to mat sizes and places the design inside the available cutting area. Check that the intended cut fits both the usable mat area and your piece of material. Cutting aids add a weeding box, weed lines or layering marks; inspect their space requirements too.

## Try a test pattern

Test Cut in the toolbar or Cut menu opens the test screen. A test is optional and does not certify a material preset. Place the test spot clear of the design and previous tests, then prepare the pattern and inspect its settings.

Follow the loading instructions, set the physical blade, and load the mat. Press Start to send the prepared pattern. Entering the screen or preparing a pattern does not start motion.

Inspect and weed the pattern. If necessary, adjust one setting at a time and try another pattern in a fresh spot. A successful pattern is a useful starting point, but fine details in the full design may need further adjustment. There is no test-cut wizard or tested-material status to maintain.

## Cut the design

Cut in the toolbar opens the cut screen when the project is cut-ready. Choose the cutter, prepare the cut and review its material settings and loading instructions. If the design changes after preparation, prepare the updated copy before cutting.

Press Start only after the physical material is ready. Consecutive test patterns and a following design cut can reuse the same loaded mat when the cutter still knows its loading state. Each requires its own Start. Unloading, disconnecting, stopping or changing users can require fresh loading.

Progress, time remaining and the blade marker are estimates. Pause waits for a safe checkpoint. Stop now interrupts the cut; after a stop, follow the loading instructions again. Escape also requests Stop while a cut is active, including when a help dialog is open.

On the cut or test screen, the corresponding toolbar button becomes Exit. Leaving a screen does not start a cut. If Start is not confirmed because a reply was lost, inspect the cutter and use Check Start status. Retry original Start uses the originally prepared copy and request, even if the design has since changed. It is never an automatic retry.

The Simulated Cameo is for practice and development. Its scenarios deliberately imitate faults; they do not describe settings to use on a physical cutter.

## Save and recover work

File > Save asks for a name and library folder the first time. Later saves update that project. Save As creates a new library project. If someone else has saved a newer revision, your edits remain available: choose Save As to preserve them separately, or Reload to use the saved version.

A session draft keeps unfinished work on the server, but a named library project is the way to retain a design deliberately. Download project saves a .cutcraft copy through your browser. Export can download a cut-preview SVG or PNG, a cut plan, or a cutter file for inspection. Exporting does not send anything to the cutter.

Uploaded designs, session drafts and library projects are server files. They are not the same as the original source files on your computer. Update from Design requires uploading the new source; a browser cannot watch the original file for changes.

## Appearance and shortcuts

View and Preferences contain units, interface text size, theme and panel layout controls. Text size ranges from 10 to 24 points; 14 is the default. Narrow windows move secondary toolbar actions into More tools.

Use Ctrl on Windows/Linux and Command on macOS: O opens, S saves, Shift+S opens Save As, Z undoes, Shift+Z redoes, and 1/2/3 select Side by side, Overlay and Cut Preview. The plus, minus and 0 shortcuts zoom comparison views or resize/fit the design in Cut Preview.
