# CutCraft-Web

**CutCraft in the browser, self-hosted.** One small home server with the Silhouette Cameo plugged
in: open it in a browser on any computer, tablet or phone, prepare a design and cut it. Nothing to
install on the computers, no USB drivers, one place for every project.

It joins two existing projects:
- [CutCraft](https://github.com/mkrzywonski/cutcraft): the desktop app that makes designs
  cut-ready and cuts them on an original Silhouette Cameo.
- [cameo-pi](https://github.com/mkrzywonski/cameo-pi): the network cut server with the library,
  phone-friendly pages, backups and MCP.

**Status:** design. See the [specification](docs/spec.md). There is no code yet.
